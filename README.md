# MeetSpace — макет для Windows

Десктопная адаптация мобильного MeetSpace: постоянное боковое меню, рабочие области для большого экрана, светлая и тёмная темы, управление мышью и клавиатурой. Это интерактивный веб-прототип для Windows 10/11 в Microsoft Edge или Google Chrome, а не установленное приложение или `.exe`.

## Запуск на Windows

Понадобится Python 3. Откройте `start-windows.bat` двойным щелчком: локальный сервер запустится на `127.0.0.1:8767`, а макет откроется в браузере. Оставьте окно терминала открытым; для остановки нажмите `Ctrl+C`.

Или выполните из корня проекта:

```powershell
py -3 start.py
```

Если порт занят, можно выбрать другой:

```powershell
py -3 start.py --port 8768
```

На macOS и Linux: `python3 start.py`. Запуск без открытия браузера: `python3 start.py --no-browser`. Сборка, npm и сервер MeetSpace не нужны.

Существующий простой сервер тоже поддерживается:

```sh
python3 meetspace-refresh-20261016/serve.py 8767
```

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| `Ctrl+K` | Поиск разделов |
| `Ctrl+,` | Настройки |
| `Alt+1` | Встречи |
| `Alt+2` | Чаты |
| `Alt+3` | Календарь |
| `Alt+4` | Записи |
| `Alt+5` | Папки |
| `Escape` | Закрыть диалог |

## Файлы и ограничения

Основной экран — `meetspace-refresh-20261016/index.html`; адаптация Windows — `desktop.css` и `desktop.js` в той же папке. Мобильная галерея сохранена в `mobile.html`, отдельные мобильные экраны — в `preview.html`. Локальные шрифты, иконки и демонстрационные материалы находятся в `assets/`.

Доступны встречи, чаты, календарь, папки, записи, несколько аккаунтов, настройки звука, видео, уведомлений и оформления. Все данные демонстрационные. Звонки, камера, микрофон, операции с аккаунтами и отправка уведомлений имитируются. Состояние интерфейса хранится в памяти до перезагрузки страницы. Исторические снимки и отчёты QA в репозитории относятся к мобильному макету на дату их создания.

## Предыдущая версия

Корневая `index.html` открывает актуальный макет и сохраняет параметры экрана и темы. Предыдущая версия доступна через `legacy.html`; её описание сохранено в `README-legacy.md`, а исходные файлы оставлены в корне репозитория.
